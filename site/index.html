WHAT A REVIEW CAN LOOK LIKE

A small bug. A meaningful finding.

Authored illustration, not fabricated Copilot output. A percentage discount was incorrectly subtracted as a currency amount. A separate downloadable report, when available, contains an actual CLI response to this synthetic example.

demo/pricing.mjs BEFORE

function totalBeforeReview(price, quantity, discountPercent) {
  return price * quantity - discountPercent;
}

// 100 x 2, 10% discount
// Actual: 190 | Expected: 180

ILLUSTRATIVE REVIEW COMMENT

Apply the discount to the subtotal

discountPercent is a percentage, not an absolute amount. Multiply the subtotal by 1 - discountPercent / 100. Add a regression test expecting 180 for (100, 2, 10).

Human approval before applying a fix
Show the corrected implementation
const subtotal = price * quantity;
return Math.round(subtotal * (1 - discountPercent / 100) * 100) / 100;

// Full implementation also validates inputs.
// Regression: totalAfterReview(100, 2, 10) === 180

FOR A REAL ENTERPRISE SERVER

GHES is a separate deployment.

A real GHES Azure deployment requires a GitHub Enterprise license file, a supported x86-64 memory-optimized VM, persistent data storage, a hostname, TLS, and administrator setup. Current GitHub guidance recommends at least 4 vCPUs, 32 GB RAM, a 400 GB root disk and a 500 GB data disk for a trial/demo. Do not use the Docker guide as a substitute.

Copilot authentication and licensing use GitHub.com or GHE.com. A GHES Git token is not a Copilot credential. Source-code use with a cloud AI service must comply with your organization's policies and outbound connectivity requirements. Native GitHub pull request review availability is a separate product/platform consideration.

Troubleshooting and teardown

Copilot login or review fails

Confirm an active cloud Copilot entitlement and applicable CLI policies. Run copilot login on the host or start the review container interactively. Authentication is intentionally ephemeral in the container; never paste tokens into this public guide. Permission denials are errors, not successful reviews.

Docker is unavailable on Windows

Install Docker Desktop, enable the WSL 2 backend, select Linux containers and confirm docker version shows both client and server. The Azure script uses ACR cloud builds so local Docker is not required for Azure deployment.

Azure role assignment or container startup fails

The deployer needs resource creation and role assignment privileges. Confirm the selected account and subscription. Check az containerapp logs show --name ghcp-guide --resource-group rg-ghes-ghcp-cli --type system. ACR pull authorization can take time to propagate; rerun the idempotent deployment after it does. Never deploy in a different subscription to bypass a denial.

Costs and cleanup

Container Apps scales to zero; requests and compute may incur charges. ACR Basic has a standing charge even when idle. This is not a zero-cost or production deployment. Delete only the dedicated demo resource group after confirming it contains no other work: az group delete --name rg-ghes-ghcp-cli --subscription YOUR_SUBSCRIPTION_ID. Keep the confirmation prompt; deletion is irreversible.
